ABOUT THE TOOL

개인 연구를 위한
데이터 연결 도구

운영자 김한결이 자신의 연구 환경에서 사용하는 도구입니다. 지정된 연구 데이터의 다운로드, 해시 검증, 오프라인 분석 및 결과 보관을 지원합니다. 연구 실행에는 로컬 컴퓨터와 OpenAI Codex 클라우드 환경이 사용될 수 있습니다.

공개 회원가입이나 불특정 다수 대상 서비스는 제공하지 않습니다. 공개 안내 사이트에는 연구 원본, 인증정보, 비공개 분석 결과가 게시되지 않습니다.

GOOGLE DRIVE ACCESS

요청하는 권한과 사용 목적

권한의 범위와 실제 사용을
구분해 설명합니다.

READ

연구 파일 읽기 및 다운로드

https://www.googleapis.com/auth/drive.readonly

이 권한은 계정의 Drive 파일 전반을 읽고 다운로드할 수 있는 범위입니다. 도구는 사용자가 연구 작업에 지정한 파일과 필요한 메타데이터를 읽는 데 사용합니다. 특정 폴더에만 한정된 권한은 아닙니다.

WRITE

앱에서 사용하는 파일 생성 및 관리

https://www.googleapis.com/auth/drive.file

앱이 생성하거나 사용자가 앱 사용을 허용한 파일을 관리하는 권한입니다. 연구 결과와 검증 기록을 새 비공개 결과 폴더에 보관하는 데 사용합니다.

계정 접근은 별도의 Google OAuth 동의 절차에서 승인합니다. 이 안내 사이트 자체는 Google OAuth 토큰을 받거나 Drive에 접근하지 않습니다.

ENGLISH OVERVIEW

Private research. Reproducible workflows.

Codex Research is a personal research utility operated by Hankyeol Kim. With the account owner's consent, it downloads selected research datasets from Google Drive, verifies file integrity, runs offline analyses, and saves results in private Drive folders created by the application.

The workflow may run on the operator's computer and in OpenAI Codex cloud environments. The read-only scope technically permits reading all Drive files; its intended use is limited to user-designated research inputs and necessary metadata. The drive.file scope is used to create and manage app-authorized output files.

This public website provides information only. It has no Google sign-in form, no file upload form, and no access to research credentials or Drive data. The tool is independently operated and is not an official Google or OpenAI product.
