현재 운영자의 승인된 개인 연구 환경에서 사용하며, 공개 회원가입이나 유료 구독을 제공하지 않습니다. Google 또는 OpenAI의 공식 제품이 아닙니다.

2. 계정 승인과 데이터 이용

사용자는 접근 권한을 가진 Google 계정과 데이터만 연결해야 하며, 각 데이터의 이용 조건을 준수해야 합니다. 계정 소유자가 Google OAuth 동의 화면에서 허용한 범위로 API 접근이 이루어집니다. 인증값은 다른 사람에게 공개하거나 공개 저장소에 게시하지 않아야 합니다.

Google Drive와 OpenAI Codex 등 외부 서비스의 이용에는 해당 서비스의 조건이 함께 적용됩니다. 데이터 처리에 관한 상세 내용은 개인정보처리방침에서 확인할 수 있습니다.

3. 연구 결과의 성격

도구는 연구 자료 처리와 분석을 지원합니다. 과거 데이터의 재현, 해시 일치 또는 테스트 통과는 미래 성과나 분석의 모든 가정이 타당함을 보장하지 않습니다. 도구의 연구 결과는 투자자문이나 매매 권유를 목적으로 제공되지 않습니다.

설명된 연구 워크플로는 실제 거래 주문을 실행하지 않습니다. 분석 결과의 검토와 이후 활용 여부는 사용자가 결정합니다.

4. 운영과 변경

개인 연구 목적의 도구이므로 상시 운영이나 특정 수준의 지원을 보장하지 않습니다. API 변경, 네트워크 상태, 권한 만료 및 실행 환경의 제약에 따라 기능이 중단될 수 있습니다. 중요한 자료의 원본과 필요한 백업은 사용자가 관리해야 합니다.

운영자는 기능과 문서를 수정하거나 운영을 중단할 수 있으며, 데이터 이용 목적이나 요청 권한이 달라지는 경우 관련 안내와 동의 절차를 갱신합니다. 적용 법률에 따른 권리를 배제하는 내용으로 해석되지 않습니다.
